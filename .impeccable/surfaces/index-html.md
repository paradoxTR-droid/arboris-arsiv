# Arboris site (index, app, kurulum)

Mode: Persuade. Audience: anyone, mostly on phones. Action: download an APK. Proof: real app names, descriptions, sizes; no screenshots exist yet.

## Direction contract

THESIS: The site is an arboretum walk; each app is a tree known by its engraved specimen tag, staked along one gravel path. Refuses the app-store icon grid and the plain text list.

OWN-WORLD: Drenched hedge green ground (#2d5b3f), black engraved laminate tags (#121815) with white-core lettering (#eef2ec), a gravel path (#b9b4a6, noise texture), grey metal stakes, blossom yellow (#f0b429) reserved for download plates. One condensed monoline face (Barlow Condensed) for engraved names, Barlow for body. No neutral greys outside gravel and stakes.

STORY: Visitor sees whose shelf this is and that it is free, walks the path reading tags, taps a yellow plate to download, or a name to read more; install help is a tag of its own.

FIRST VIEWPORT: Wide engraved ARBORIS plate across the top with a two-line intro; below, the gravel path starts down the center and the first two tags stand on alternating sides, each with name, one-line meta, description and a yellow APK plate visible without scrolling.

FORM: Arboretum specimen tags, position 4 of 7 on the grounded list. seed:b7168e5de04b8662. Signature interaction: tags settle into the ground on their stakes as they enter the viewport; unavailable APKs show an empty frame instead of a yellow plate.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
